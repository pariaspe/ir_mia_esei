About the course

The practical part of the course is 10 hours over four sessions on Unibotics, which runs JdeRobot RoboticsAcademy (Gazebo + ROS 2, with Python written in the browser). Installation steps can be found at Unibotics user guide. The platform works in Windows, Linux and MacOS via docker, and it is recommended to use a recent version of Firefox or Chrome.
